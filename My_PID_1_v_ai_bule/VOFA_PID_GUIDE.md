# VOFA+ PID 在线调参

## 连接

- STM32 `PA2 (VOFA_TX)` -> USB 转串口模块 `RX`
- STM32 `PA3 (VOFA_RX)` -> USB 转串口模块 `TX`
- STM32 `GND` -> USB 转串口模块 `GND`
- 串口必须使用 3.3 V 电平，不要把 5 V 接到 STM32 引脚

## VOFA+ 设置

1. 新建串口设备，选择 USB 转串口对应的 COM 口。
2. 波特率设为 `115200`，数据位 `8`，停止位 `1`，无校验，无流控。
3. 协议选择 `FireWater`，打开串口。
4. 波形会自动出现：`target`、`actual`、`output`、`error`。

固件每 50 ms 发送一帧曲线数据。每条下发命令都必须以换行 `\n` 或回车 `\r` 结束。

## 在线命令

| 命令 | 作用 | 示例 |
| --- | --- | --- |
| `T=数值` | 目标转速，单位 rpm | `T=100` |
| `P=数值` 或 `VP=数值` | 速度外环 Kp | `VP=0.30` |
| `I=数值` 或 `VI=数值` | 速度外环 Ki | `VI=0.10` |
| `D=数值` 或 `VD=数值` | 速度外环 Kd | `VD=0.10` |
| `IP=数值` | 电机内环 Kp | `IP=0.09` |
| `II=数值` | 电机内环 Ki | `II=0.90` |
| `ID=数值` | 电机内环 Kd | `ID=0` |
| `GET` | 返回目标值和全部 PID 参数 | `GET` |
| `RESET` | 清除两个 PID 的积分、误差和输出状态 | `RESET` |
| `STOP` | 目标值归零并清除 PID 状态 | `STOP` |

可在 VOFA+ 的“命令”控件中为常用值创建按钮，例如 `T=100\n`、`P=0.2\n`、`STOP\n`。固件返回以 `#` 开头的确认或错误信息，可在原始数据页查看。

参数和目标值允许范围为 `-1000` 到 `1000`。在线修改只保存在 RAM，复位后恢复 `main.c` 中的默认值；确定最终参数后再把默认值写回 `PID_Init`。

## 建议调参顺序

1. 先发送 `STOP`，确认电机停止且编码器方向正确。
2. 保持 `I=0`、`D=0`，从较小的 `P` 开始增加，观察 `actual` 是否能跟随 `target`。
3. 出现持续振荡后降低 `P`，再小幅增加 `I` 消除静差。
4. 只有存在明显超调且噪声不大时再少量增加 `D`。
5. 每次切换一组差异较大的参数前发送 `RESET`，避免旧积分影响判断。

当前工程是两级 PID。外环输出作为内环目标，但内环反馈仍是上一拍 PWM，不是真实电流；因此 `IP/II/ID` 只适合验证现有代码，不能替代电流采样后的真正电流环调试。
